## Quick Recommendations

- **Best overall:** [Paper](/paper)
- **Best for customization:** [Purpur](/purpur)
- **Best for mods:** [Fabric](/fabric)
- **Best for vanilla experience:** [Vanilla](/vanilla)

## Server Software Categories

Minecraft server software falls into several categories based on what they support and how they modify the game.

### Plugin Servers

These servers support plugins through the Bukkit/Spigot API. They are the most popular choice for multiplayer servers.

#### Paper

[Paper](/paper) is the most popular server software. It is a fork of Spigot with significant performance improvements and bug fixes. Paper is the recommended choice for most servers.

- Best performance of any plugin server
- Full Spigot plugin compatibility
- Active development and community
- Fixes many vanilla bugs and exploits

<DownloadButton project="paper" />

#### Purpur

[Purpur](/purpur) is a fork of Paper that adds even more configuration options and gameplay features. Great for servers that want maximum customization.

- All Paper features plus more
- Extensive configuration options
- Fun additions like rideable mobs
- Perfect for custom game modes

<DownloadButton project="purpur" />

#### Spigot

[Spigot](/spigot) is the original plugin server that Paper is based on. It is still widely used but Paper is generally recommended for better performance.

<DownloadButton project="spigot" variant="secondary" />

### Mod Loaders

Mod loaders allow you to install Minecraft mods that modify the game more deeply than plugins.

#### Fabric

[Fabric](/fabric) is a lightweight mod loader focused on performance and quick updates. It has become the preferred choice for many mod developers.

- Fast updates for new Minecraft versions
- Lightweight and performant
- Growing mod ecosystem
- Great for performance mods

<DownloadButton project="fabric" />

#### Forge / NeoForge

[Forge](/forge) is the longest-running mod loader with the largest mod library. [NeoForge](/neoforge) is a modern fork that continues development.

- Largest mod selection
- Best for complex modpacks
- Slower updates than Fabric

<DownloadButton project="forge" />

### Proxies

Proxies allow you to connect multiple servers together into a network.

#### Velocity

[Velocity](/velocity) is a modern, high-performance proxy. It is the recommended choice for new server networks.

<DownloadButton project="velocity" />

#### BungeeCord / Waterfall

[BungeeCord](/bungeecord) is the original Minecraft proxy. [Waterfall](/waterfall) is a fork with additional features and improvements.

## Conclusion

For most Minecraft servers, [Paper](/paper) is the best choice. It offers the best balance of performance, stability, and plugin compatibility.

If you need mods, choose between [Fabric](/fabric) (modern, fast) or [Forge](/forge) (largest mod library) based on which mods you want to use.
