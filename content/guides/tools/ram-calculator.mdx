## How to Use the Recommendation

The calculator gives a starting range. Allocate the lower number first, monitor TPS and memory usage, and increase only if you see spikes or warnings.

<CalloutBox type="info" title="Start Small">
Allocating more RAM than your server needs can cause longer garbage collection pauses. Start low and increase gradually.
</CalloutBox>

## Extra Tips

- Use the same value for `-Xms` and `-Xmx`
- Leave 2GB RAM for the operating system
- Pre-generate your world to reduce chunk generation lag
