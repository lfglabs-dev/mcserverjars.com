## Step 1: Download Spigot

<DownloadButton project="spigot" label="Download Spigot" />

Spigot is the classic Bukkit-based server software for plugins.

## Step 2: Create a Start Script

```bash
java -Xms4G -Xmx4G -jar server.jar --nogui
```

Need optimized flags? Use the [Startup Flags Generator](/guides/startup-flags-generator).

## Step 3: Configure server.properties

Set your `motd`, `max-players`, and `view-distance`. Use our [server.properties generator](/guides/server-properties-generator) for a clean config.

## Step 4: Install Plugins

1. Download plugin jars
2. Place them in the `plugins` folder
3. Restart the server

<CalloutBox type="info" title="Paper vs Spigot">
Paper is a high-performance fork of Spigot. If you want better performance and fixes, consider [Paper](/paper).
</CalloutBox>

## Troubleshooting

If your server fails to start, check your Java version and RAM allocation. See [Common Server Errors](/guides/common-server-errors).
