## Step 1: Download Purpur

<DownloadButton project="purpur" label="Download Purpur" />

Purpur is a feature-rich fork of Paper with extra configuration options and gameplay tweaks.

## Step 2: Start Your Server

Create a start script:

```bash
java -Xms4G -Xmx4G -jar server.jar --nogui
```

Use the [Startup Flags Generator](/guides/startup-flags-generator) for better performance.

## Step 3: Configure Purpur

Purpur adds a `purpur.yml` file with extensive settings:

- Entity behavior tweaks
- Gameplay quality-of-life options
- Customization for mobs and mechanics

## Step 4: Install Plugins

Purpur is fully compatible with Spigot plugins. Drop plugin jars into the `plugins` folder and restart.

## Purpur vs Paper

Purpur is best if you want maximum customization. Paper is simpler and slightly more conservative. Compare them in [Paper vs Purpur](/guides/paper-vs-purpur).
